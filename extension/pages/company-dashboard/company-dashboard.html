Company Dashboard

Unternehmens-Dashboard verwalten

Unternehmens-Dashboards werden direkt unter company_dashboard/[ordner]/dashboard.json verwaltet und greifen weiter auf dieselben Verbrauchsdaten zu.

Persönliches Dashboard Einstellungen
Verwaltung
Start
Erstelle ein neues Unternehmens-Dashboard.
Neues Dashboard
Das erstellte Dashboard nutzt das bestehende Unternehmenslayout und wird danach direkt geöffnet.
Noch kein Logo ausgewählt
Das Logo wird aus deiner lokalen Datei gelesen und direkt im Dashboard gespeichert. Die Extension liefert keine Firmenlogos mit.
Abteilungen
Die erste Abteilung wird standardmäßig als eigene Abteilung verknüpft. Die Verbrauchsdaten bleiben global erhalten und werden nur visuell mit dieser Konfiguration verbunden.
Vorhandene Dashboards
Bereits gefundene Dashboard-Ordner können hier geöffnet und gepflegt werden.
Noch keine gespeicherten Unternehmens-Dashboards vorhanden.
